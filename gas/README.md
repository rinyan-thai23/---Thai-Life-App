# タイ暮らし：GAS手動更新

## 手動で実行する関数

| 関数 | 内容 | 将来の頻度（タイ時間） |
|---|---|---|
| `updateExchangeRates` | Frankfurter / ECBの参考レートを取得 | 毎日午前3時ごろ |
| `updateLuckyNumbers` | 00〜99から重複しない3つを生成 | 毎日午前3時ごろ |
| `updateHolidays` | BOT公式の当年・翌年の銀行休日を取得 | 毎月1日午前3時ごろ |

**トリガーは作成しません。** 関数はApps Scriptエディターから個別に実行してください。
スプレッドシートを開き直すと「タイ暮らし」メニューからも実行できます。
同じ日に数字の関数を再実行すると、再抽選します。宝くじ分析は行いません。

## 初回

1. スプレッドシートに紐づくApps Scriptを開く。
2. 初期設定がまだなら `setupThaiLife` を実行。既存シートは上書きしません。
3. `updateExchangeRates`、`updateLuckyNumbers`、`updateHolidays` をそれぞれ手動実行し、求められたGoogle権限を許可。
4. 各シートと「出力」シートのJSONを確認。

各更新関数は対象シートと公開用JSONを更新します。外部取得・検証に失敗した場合は前回値を残し、実行エラーとして通知します。書き込みエラー時は元データへの復元を試みます。
為替にはデータ日 `as_of` と取得日時 `updated_at`、数字には対象日 `date` と生成日時 `updated_at`、休日には確認日 `checked_at` を保存します。
週末などは為替のデータ日が前営業日になります。10日を超えて古い値は受け入れません。

## アプリへの接続

1. GASで「デプロイ → 新しいデプロイ → ウェブアプリ」を選ぶ。
2. 実行ユーザーは「自分」、アクセスできるユーザーは「全員」に設定してデプロイする。
3. 発行された `/exec` URLを `docs/config.js` の `dailyUrl` に設定する。
4. `docs` の変更をGitHubへpushしてPagesを更新する。
5. ログアウト状態でもURLからJSONを取得でき、アプリにデータ日と数字が表示されることを確認する。

初回は手動更新後にデプロイしてください。GASコードを後で変更した場合は「デプロイを管理」から新しいバージョンへ更新します。シートの値だけを更新する場合、再デプロイは不要です。
Google Workspaceの制限で匿名公開できない場合はこの方式は使えません。
`doGet` は保存済みJSONを返すだけで、外部データの収集や乱数生成は行いません。
公開対象は為替・数字・休日のみで、個人の期限やスプレッドシートIDは含みません。

`dailyUrl` が空の間は同梱の `docs/daily.json`（サンプル）を使用します。GASを実行するだけではこのファイルは更新されません。
接続設定後は起動時・画面復帰時・更新ボタンでGASから取得します。通信失敗時は前回成功したデータを表示し、更新失敗を表示します。
`runManualExport` / `showExportDialog` による手動JSON出力も利用できます。

## 休日の範囲

BOTの銀行休業日が対象です。官公庁・入管の閉庁日は推定しません。
バンコク限定日はBangkokに限定。南部の追加宗教休日など、公式カレンダーの注記だけにある休日は取り込みません。
当年・翌年の公式一覧を取得し、未発表の翌年が空リストなら既存の翌年データを保持します。通信エラーや形式変更時は更新全体を中止します。
手入力の官公庁・祝日、別出典の銀行休日は残します。既存の古い年度は自動削除しません。JSONが45,000文字を超えた場合は古い休日を整理してください。
既知の名称は日本語、未登録の名称は公式英語名で表示します。

## 宝くじ履歴

宝くじ履歴シートの新規作成・分析は廃止しました。既存シートがある場合はデータ保護のためそのまま残し、参照も公開もしません。
旧 `installNoonExportTrigger` は削除しました。以前手動登録したトリガーがある場合、この変更では削除されません。Apps Scriptのトリガー画面で確認してください。
